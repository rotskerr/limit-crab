# Claude Limits для Windows

Краб показує ліміти Claude: сесія 5 годин і тижневий.

- **Великий краб зліва на панелі задач** (за замовчуванням): краб і цифри `5г 12%` / `Т 19%` у два рядки.
  Цифра від 70% помаранчева й жирна, від 90% червона. Під час повноекранного відео чи гри віджет ховається.
- **Або маленька іконка в треї** (біля годинника) — якщо зняти галочку «Великий краб зліва на панелі задач»,
  або якщо панель задач ховається сама. Знизу на іконці дві смужки: сесія і тиждень.
- **Наведи мишку** — підказка `Claude · 5г 16% · Т 12%`.
- **Клік** — меню з деталями, «Графік використання…», «Оновити зараз», дебаг станів краба,
  вибір великий/маленький краб, «Запускати при вході в Windows» і «Вийти».
- **Графік** — сесія і тиждень за 24 години або 7 днів; наведи мишку на графік, щоб побачити значення.
  Історія збирається з кожним оновленням (раз на 5 хв), тож заповнюється поступово.

### Витівки краба (лише Windows)

| Що | Коли |
|---|---|
| Стежить очима за мишкою | мишка поруч із віджетом |
| Червоніє, усміхається, підстрибує | мишка над віджетом |
| П'є каву, з кружки йде пара | 8:00–10:00, сесія < 75% |
| Темні окуляри на 10 с | випадково раз на 15–30 хв |
| Гуляє боком по панелі задач (від половини до всього шляху до кнопки «Пуск»), махає іконкам і повертається | випадково раз на 25–45 хв (не вночі й не від 90%) |
| Гарбуз на голові | 25 жовтня – 1 листопада |
| Сумує: дрімає, визирає тебе, сльозинка | 10+ хв ніхто не чіпав мишку й клавіатуру |
| Радіє: махає обома клешнями, сердечко над головою | щойно повернувся за комп'ютер |
| Бовтає ногами в повітрі; кинь — полетить, відскочить від панелі й стін, запаморочиться й повернеться (пішки чи летячи) | схопи краба мишкою й потягни / махни й відпусти |
| Ловить курсор: стрибає до мишки, клацає клешнею з іскрами, стрибає назад | одна зі сцен раз на 25–45 хв |
| Кажан замість чайки · сніг під час сцен · сердечка · синьо-жовтий прапорець | Хелловін · зима · 14 лютого · 24 серпня й 28 червня |
| Танцює під музику (клешні в такт), у кібер-режимі — неоновий еквалайзер | коли на комп'ютері грає звук ~1 с і довше |

### Кіберпанк-режим (пункт меню, за замовчуванням увімкнений)

| Що | Коли |
|---|---|
| Неоновий краб: світний імплант біля ока, хромовані клешні, рожеве світіння | завжди |
| **Глітч**: краб двоїться червоним/бірюзовим, рветься на смуги, зникає на мить; цифри смикаються | сесія чи тиждень від 95% |
| **Кіберпсихоз**: 5–7 телепортів по панелі з бірюзовим променем | від 95%, раз на 2–5 хв |
| Неоновий слід у русі · після падіння голограмою «телепортується» додому | прогулянки, кидки, сцени |
| Чайка пролітає над панеллю, краб присідає від страху, потім сердиться | випадково раз на 40–90 хв |
| Обідає рибкою | 13:00–13:30 |
| Диско: куля, вогники, танцює | п'ятниця 17:00–20:00 |
| Сонний: ледве розплющує очі, позіхає, мішки під очима | понеділок 8:00–11:00 |
| Батут: стрибає з дому на батут, відскакує, біжить по краю панелі й сідає на значок відкритої програми, потім летить додому | одна зі сцен раз на 25–45 хв |
| Хованка: заходить за логотип «Пуску», визирає одним оком, повертається | одна зі сцен раз на 25–45 хв |

Усе можна подивитись у меню «Дебаг: стани краба» (там же «Піти погуляти зараз», «Батут зараз», «Сховатися за «Пуск»», «Прилетіла чайка», «Ти повернувся»).

Ресурси: ≈0.1% процесора й ≈35–40 МБ пам'яті; поки тебе немає за комп'ютером, краб малює вчетверо рідше.

## Встановлення

Нічого встановлювати не треба: програма збирається компілятором C#, який уже є у Windows.

1. Двічі клікни `build.cmd` (або запусти в терміналі). Він збере `ClaudeLimits.exe`, покладе його в
   `%LOCALAPPDATA%\Programs\ClaudeLimits` і запустить.
2. Клікни по крабу зліва на панелі задач і увімкни «Запускати при вході в Windows».
   (Якщо обрав маленьку іконку в треї: Windows 11 ховає нові іконки під стрілочку `^` — перетягни краба звідти.)

Щоб оновити програму після змін у коді — знову запусти `build.cmd`.

## Де що лежить

| Що | Де |
|---|---|
| Код | `windows/ClaudeLimits.cs` (один файл) |
| Програма | `%LOCALAPPDATA%\Programs\ClaudeLimits\ClaudeLimits.exe` |
| Історія для графіка (~30 днів) | `%APPDATA%\ClaudeLimits\history.csv` |
| Журнал непередбачених помилок (якщо краб поводиться дивно — дивись сюди) | `%APPDATA%\ClaudeLimits\errors.log` |
| Останні цифри, пауза після 429, вибір великий/маленький краб | `%APPDATA%\ClaudeLimits\state.json` |
| Токен (читається, не копіюється) | `%USERPROFILE%\.claude\.credentials.json` (його створює Claude Code) |
| Автозапуск | реєстр `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`, значення `ClaudeLimits` |

Перевірити вигляд усіх станів краба без запуску: `ClaudeLimits.exe --preview preview.png`.
Графік на вигаданих даних: `ClaudeLimits.exe --preview-graph graph.png` (зробить `graph.png` і `graph-week.png`).
Автотест (спершу закрий програму): `ClaudeLimits.exe --selftest` — сам клікне, схопить і кине краба, напише результат.
